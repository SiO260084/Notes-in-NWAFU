\section{研究背景}

\subsection{重要性}

\begin{enumerate}
	\item 长期施化肥导致土壤性质改变，变得不适合猕猴桃生长，施有机肥可以改善土壤条件，使其适合猕猴桃生长。
	\item 猕猴桃果园内空间比较狭窄，不适合机器施肥，而人工施肥效率低、均匀度差、肥料利用率低且劳动强度高。
	\item 中国缺乏小型郁闭果园的有机肥施肥机械，国外的有机肥施肥机械不适配中国的情况。
	\item 中国的猕猴桃在种植面积、产量和消费均位居世界第一，是世界上最大的猕猴桃生产国。
	\item 郁闭果园在中国普遍存在，而且不仅限于猕猴桃，其它品种果园也有同样的问题。
\end{enumerate}

\subsection{创新点}

针对郁闭性果园的特殊环境设计了\strong{防挂枝}的外形。

\subsection{研究目标}

\begin{enumerate}
	\item 排肥抛肥机构
	\item 防挂枝外形
	\item 肥料混合机构
\end{enumerate}

\subsection{施肥车方案}

\begin{enumerate}
	\item 调查猕猴桃、枣和葡萄等果园行间的可通行尺寸
	\item 确定外形尺寸参数和肥箱容积
	\item 确定方案为牵引式的施肥车 ✅
\end{enumerate}
